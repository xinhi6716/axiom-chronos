# Evolve harness

## Failure classes

- MISSING CONTEXT → a map or retrieval rule
- WRONG TOOL → a better tool description or routing
- BAD OUTPUT → a validator or stronger contract
- REPEATED LOOP → a retry cap and escalation
- UNSAFE ACTION → a permission gate
- LOST DECISION → durable state
- UNKNOWN → tracing and evidence capture

## Checklist

- success defined up front
- the map, not everything
- tool contracts
- isolation
- durable decisions
- evidence on risky steps
- approval for irreversible actions
- retry caps and budgets
- resume
- explainable traces
- failures updating guides or tests
- rollback
