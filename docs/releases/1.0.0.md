Axiom Chronos 1.0.0 is the first release after the 0.2.0 beta. One binary runs the CLI, the MCP bridge, the hooks, work tracking and memory for Claude Code with Codex workers.

## What changed since 0.2.0-beta.1

- **Astra plans every wish.** The `[astra]` marker and `--astra` flag are gone; Astra thinks first, `chronos:critic` gives the second ruling and the core rules.
- **Claude reviews, Codex builds.** Code review goes to `chronos:reviewer` and plan review to `chronos:critic`, so Codex (GPT) work is always reviewed by another model family. Gemini is removed; the core writes the plain-language report itself.
- **Real progress during long Codex turns.** The bridge reports Codex events as MCP progress notifications, so long turns are not cut off as idle.
- **Stricter gates in the binary.** Unit claims are kept on disk with an attempt id; a review only counts for the exact files it saw; reviews are bound to their unit; units must stay in their module's paths; ACCEPT runs automatically when a unit's VERIFY passes.
- **Steadier runs.** Memory writes skip duplicates, the memory keeper runs in the foreground, process-tree kills report why they failed, and research plans must name claims, evidence, baselines and fixed thresholds.

## Install

Download the binary for your platform below, put it on your `PATH` as `axiom`, then run `axiom doctor`. Or build it with Rust:

```
cargo install --git https://github.com/xinhi6716/axiom-chronos --tag v1.0.0 --locked
```

Data in `~/.axiom` from 0.2.0 stays readable.

## 繁體中文

Axiom Chronos 1.0.0 是 0.2.0 測試版之後的第一個正式版。一個執行檔就包含 CLI、MCP bridge、hooks、工作追蹤與記憶，讓 Claude Code 搭配 Codex 工作。

### 相較 0.2.0-beta.1 的改變

- **每個願望都由 Astra 先想。** 拿掉 `[astra]` 與 `--astra`；Astra 先規劃，`chronos:critic` 第二審，核心裁決。
- **Claude 審查、Codex 施工。** 程式由 `chronos:reviewer` 審、計畫由 `chronos:critic` 審，Codex（GPT）的成果一定由另一家模型審查。移除 Gemini，報告由核心直接用白話寫。
- **長時間的 Codex 執行會回報真實進度**，不會再被當成閒置而中止。
- **更嚴格的程式關卡。** 單元占用寫在磁碟並帶執行 ID；審查只對它看過的那份檔案有效，也綁定所屬單元；單元不能改到模組範圍外；VERIFY 通過就自動驗收。
- **更穩定。** 記憶不重複寫入、記憶代理在前景執行、程序樹終止失敗會說明原因、研究計畫必須寫明主張、證據、基線與事先固定的門檻。

### 安裝

下載下方對應平台的執行檔，以 `axiom` 為名放進 `PATH`，再執行 `axiom doctor`。或用 Rust 建置：

```
cargo install --git https://github.com/xinhi6716/axiom-chronos --tag v1.0.0 --locked
```

`~/.axiom` 裡 0.2.0 的資料仍可讀取。
