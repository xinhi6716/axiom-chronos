Axiom Chronos 2.0.0 adds a desktop app and a large round of changes to the engine: it spends fewer tokens, stops more kinds of failure, and has new commands. The full list is in [CHANGELOG.md](../../CHANGELOG.md).

## Highlights

- **Desktop app.** `chronos` (or `axiom app`) is a native window for making a wish, watching it and steering it: a checklist, a live graph, details for every unit, Wishes, Memory, Usage and Settings. Windows only for now.
- **Fewer tokens.** One dispatcher per module, handoff to a fresh dispatcher at 150k tokens with state kept, a report digest, review packs, bounded hot memory and the one-hour cache.
- **Safer and steadier.** Races and lock takeover fixed, a guard against links out of the project, verdicts bound to the reviewed tree, bounded child processes.
- **New commands.** `axiom review`, `axiom lint`, `axiom usage`, `axiom wait`, `--advanced-research` and `--resume <id> <text>`.
- **Backup reviewer.** agy (Gemini) can review when Codex cannot. It never blocks.

## Optional and paid

The desktop app, agy, the code graph and the advanced research council are optional. Only the council costs extra money: it is off by default, and Fable is capped at $5 unless you change it.

## Install

Download the binary for your platform below. `axiom` is the command line; on Windows, `chronos.exe` is the desktop app. Put `axiom` on your `PATH`, then run `axiom doctor`. Or build it with Rust:

```
cargo install --git https://github.com/xinhi6716/axiom-chronos --tag v2.0.0 --locked
cargo install --git https://github.com/xinhi6716/axiom-chronos --tag v2.0.0 --locked --features app --bin chronos
```

Data in `~/.axiom` from 1.0.0 stays readable.

## 繁體中文

Axiom Chronos 2.0.0 加入桌面應用程式，並大幅改進引擎：更省 token、擋下更多種失敗、新增指令。完整清單見 [CHANGELOG.md](../../CHANGELOG.md)。

### 重點

- **桌面應用程式。** `chronos`（或 `axiom app`）是原生視窗，可許願、觀看並調整進行中的工作：待辦清單、即時圖、每個單元的詳情，以及願望、記憶、用量與設定畫面。目前僅提供 Windows。
- **更省 token。** 每個模組一個調度員、達 150k token 時帶著狀態交棒給新調度員、報告摘要、審查包、有上限的熱記憶與一小時快取。
- **更安全穩定。** 修正競爭與鎖接管、擋下指向專案外的連結、審查結論綁定被審查的檔案、子程序有上限。
- **新指令。** `axiom review`、`axiom lint`、`axiom usage`、`axiom wait`、`--advanced-research`、`--resume <id> <文字>`。
- **備用審查員。** Codex 無法審查時可由 agy（Gemini）接手，且絕不會卡住流程。

### 選用與費用

桌面應用程式、agy、程式碼圖與進階研究議會都是選用的。只有議會會額外花錢：預設關閉，Fable 預設上限 $5。

### 安裝

下載下方對應平台的檔案。`axiom` 是命令列；Windows 的 `chronos.exe` 是桌面應用程式。把 `axiom` 放進 `PATH`，再執行 `axiom doctor`。或用 Rust 建置（指令見上）。

`~/.axiom` 裡 1.0.0 的資料仍可讀取。
