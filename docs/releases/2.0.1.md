# Axiom Chronos 2.0.1

Axiom Chronos 2.0.1 makes advanced research budgets configurable and gives the council an ordered planning dialogue, one independent review and replies to objections. See [CHANGELOG.md](../../CHANGELOG.md).

## Highlights

- **Desktop strip.** Fresh plan snapshots hide unavailable quota windows; unseen or stale readings keep a dash and last-known tooltips. Celestial vector glyphs show reported running counts by model, with full model tooltips, tighter dense spacing and a 380 px Mini fallback to the parallel total.

- **Machine-wide Codex cap.** `AXIOM_CODEX_MAX_PARALLEL` is a positive integer, default 48; invalid values stop with the variable and value. Chronos bridge workers, review and council Astra turns share OS-locked slots in the data home's `codex-slots/` (normally `~/.axiom/codex-slots/`), released on exit or crash. Full pools wait with cancellation, timeout and wait notes; personally started Codex runs are excluded. Wishes export the cap to batches; Settings saves it for app launches, while the existing quota refresh and `axiom doctor` report occupancy. 全機 Codex 並行上限預設 48，可在設定調整；等待支援取消，程序崩潰不會遺留占用。

- **Configurable budgets.** Set `AXIOM_FABLE_CAP_USD`, `AXIOM_ASTRA_TOKEN_CAP`, `AXIOM_ARGON_TOKEN_CAP` and `AXIOM_COUNCIL_ROUNDS`. Defaults remain $5, 200k and 400k tokens; each dialogue phase allows up to 3 rounds. Positive values are required, tokens and rounds are whole numbers, and Fable above $200 is refused as probably a typo. Invalid values identify the variable and received value before a wish starts. The startup notice states effective caps.
- **Three phases.** A: Astra speaks first, then Fable responds, until whole-plan approval with no open rebuttal or the round/budget limit. B: Argon (Gemini 4) reviews once, seeing the agreed plan or final positions and disputes under neutral labels. C runs only for objections: Astra then Fable settle each objection with a change or a reason for rejection. Argon never returns; the core rules from phase and stance history. Failed Fable ends its phase; failed or capped Argon is reported as not reviewed. Astra's original plan survives.
- **CLI and desktop.** `axiom wish --advanced-research --fable-cap 20 --astra-cap 600000 --council-rounds 3 "fix the bug"`. Overrides require the research switch. Settings persists all four budgets and shows validation inline. The New wish switch starts off each time; when on it shows the effective budgets and a Settings link.

## Optional and paid

The council stays off by default. Fable's cap covers the council's calls for the brief; token budgets are separate and do not imply equal dollar costs. Model services use their own quotas. Usage dollars remain API-price equivalents, not subscription charges.

## Install

Download and extract `axiom-chronos-2.0.1-windows-x64.zip`, then run:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

On Linux, extract `axiom-chronos-2.0.1-linux-x64.tar.gz` and run `sh ./install.sh`. Close running Chronos programs before upgrading; data in `~/.axiom` stays readable. Installers, options and prerequisites are unchanged from [2.0.0](2.0.0.md).

Build from Rust:

```sh
cargo install --git https://github.com/xinhi6716/axiom-chronos --tag v2.0.1 --locked --bin axiom
cargo install --git https://github.com/xinhi6716/axiom-chronos --tag v2.0.1 --locked --features app --bin chronos
```

The desktop build is for Windows.

## Known limits

Protocol verification uses scripted stand-ins. No live council or model call is part of this release's checks. Argon reports tokens at completion, so its cap is checked after its single call; a capped answer is not counted as a review. Fable streams usage, with its final totals also accounted for. Existing 2.0.0 limitations still apply.

## 繁體中文

Axiom Chronos 2.0.1 讓進階研究預算可調整，並將議會改為有序規劃對話、一次獨立審查與異議答辯。完整清單見 [CHANGELOG.md](../../CHANGELOG.md)。

### 重點

- **桌面底欄。** 新鮮方案快照未提供的額度視窗會隱藏；未觀測或過期資料保留破折號與「最後已知」提示。天體向量圖符顯示各模型回報的即時並行數，提示列出完整模型名稱；密集模式縮小間距，380 px 迷你視窗放不下時只顯示並行總數。

- **可調整預算。** 設定 `AXIOM_FABLE_CAP_USD`、`AXIOM_ASTRA_TOKEN_CAP`、`AXIOM_ARGON_TOKEN_CAP`、`AXIOM_COUNCIL_ROUNDS`。預設金額與 token 上限維持 $5、200k、400k；兩個對話階段各最多 3 輪。數值須為正數，token 與輪數須為整數；Fable 超過 $200 視為可能誤植而拒絕。無效值會在啟動前指出變數與收到的值，啟動訊息列出實際上限。
- **三階段協定。** A：每輪 Astra 先、Fable 後，直到整體批准且無未解反駁，或到達輪數／預算上限。B：Argon（Gemini 4）只審一次，以中性標籤閱讀共識計畫，或雙方最後立場及未解爭議。C 僅在有異議時進行：Astra、Fable 依序用具體修改接受異議，或附理由駁回。Argon 不再被呼叫；核心依階段與立場歷程裁決。Fable 失敗會結束當前階段，Argon 失敗或超額則註明未審查；Astra 原計畫保留。
- **CLI 與桌面。** 使用上方指令覆寫預算，三個預算旗標必須搭配 `--advanced-research`。「設定 → 進階研究預算」保存四項數值並行內顯示錯誤。每次開啟許願視窗，研究開關仍預設關閉；開啟後顯示實際預算與設定連結。

### 選用與費用

議會預設關閉。Fable 金額涵蓋該 brief 的議會呼叫；各模型 token 額度獨立，不能視為相同金額。模型服務仍使用各自額度，Usage 金額是 API 定價等值金額，並非訂閱帳單。

### 安裝

Windows 解壓 `axiom-chronos-2.0.1-windows-x64.zip` 後執行上方 PowerShell 安裝指令。Linux 解壓 `axiom-chronos-2.0.1-linux-x64.tar.gz` 後執行 `sh ./install.sh`。升級前先關閉 Chronos；`~/.axiom` 資料仍可讀取。安裝選項與必要工具同 [2.0.0](2.0.0.md)，也可用上方 Rust 指令建置；桌面僅支援 Windows。

### 已知限制

協定驗證使用腳本替身，本版檢查不啟動真實議會或模型呼叫。Argon 在單次呼叫結束後才回報 token，超額答案不算完成審查；Fable 依串流使用量及結束總數計費。2.0.0 的既有限制仍適用。
