# Bridge

`axiom bridge` serves MCP over stdio. Call `dispatch` with `project`, canonical `repo_root`, `request_id`, and a tagged `action`: `start`, `decide`, `resume`, `status`, or `cancel`. Reuse the same request id and identical input after transport loss; do not redispatch unknown writes. Status reads the checkpoint without launching a model. Resume does not authorize retry of an unknown write. A host disconnect does not guarantee process survival or an automatic wakeup.

The CLI prints the request id before waiting and then a boundary JSON object. `max_wait_ms=0` means no caller-side deadline; execution budgets remain separate. `needs_intent_review` requires an explicit decision; `ready_to_commit` is not released. Errors and unknown outcomes must not be reported as successful installation.

The plugin package and versioned Rust executable are separate. Installed full-workflow acceptance remains a separate gate; consult the [guide](../README.zh-TW.md). Start and approved Decide execute the assembled pipeline; no normal-path capability placeholder remains. Local RPC regression covers research/reject with zero engineering, and approval through overlapping Terra units, mandatory SOL, independent frozen command callbacks, memory and the original ready_to_commit response. This is not independent installed/live acceptance.


## Runtime authority

The current external Astra medium remains the sole core. Terra medium dispatchers are read-only dynamic-tool coordinators. Independent research is Astra max; a fresh Astra high plan freezes scoped units and executable check IDs/specifications. Rust executes baseline checks before engineering, independent ready Terra units concurrently, mandatory SOL high integration, fresh Astra high verification and Terra medium verified-memory recording. Assembly writes use the plan’s explicit `assembly_scope` or the engineering scope union. Optional `kind:content` units use read-only Luna for non-engineering artifacts, never engineering. Role profiles are source-owned resources, not native agent registrations; leaves have only their compact brief, selected current-repository memory summaries and required context, no root chat.

Dynamic callback handlers capture run/attempt/purpose/generation/thread/turn identity. Model-supplied role, command or repository overrides are rejected. `verify_run({check_id})` resolves the frozen command in Rust. Same-provider verification is valid with a distinct role/attempt/thread; writer terminal completion cannot establish verification. Terminal delivery waits for callbacks received before the matching terminal, not a quiet-time heuristic. Post-terminal requests are rejected.

The dedicated command-only AppServer launches with process cwd=scratch as well as command cwd=scratch; workspaceWrite opens only scratch and excludes ambient temporary write roots. Product and scratch must not overlap. Checks use `{repo}` and `{scratch}` substitutions, explicit manifest paths or prepare a scratch copy for tests requiring project cwd. Rust redirects target and temporary output to scratch. `AXIOM_TEST_PYTHON` selects native Python for regression fixtures, not WindowsApps aliases. This runner never starts another LLM core.

`max_wait_ms=0` is the supported blocking contract; nonzero values are rejected. Model execution budgets are 1800 seconds; each frozen command has its own finite 1–1800 second budget. Request inputs/results and attempt events are durable; resume reconciles saved reports/history and does not blindly duplicate writing attempts. Prepared work can be dispatched; unknown work retains scope reservations until terminal or trusted repair evidence. Pstack projections are derived from real run/scope/check/review evidence and current source snapshots, never from a fabricated success receipt.

`ready_to_commit` is a legitimate minimal local submission/completion boundary. Generic projects need no remote and no Rust package release. Commit/push/install remain external core authority. Legacy creative/astra/no-architect flags are intent hints only; max-turns is explicitly unsupported. Compatibility `gemini_preview` and `review_code` names route to Codex Astra, not agy/Gemini.
