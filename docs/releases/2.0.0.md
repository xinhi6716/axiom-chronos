Axiom Chronos 2.0.0 adds a Windows desktop app, install packages and engine changes that reduce repeated context and stop more kinds of failure. The full list is in [CHANGELOG.md](../../CHANGELOG.md).

## Highlights

- **Desktop app.** `chronos` opens Run, Wishes, Memory, Usage and Settings. Claude and Codex have a remaining-quota strip with an hourglass per quota window. There is a mini window with optional always-on-top, focus mode, comfortable or dense layouts, right-click menus, undo, tooltips and keyboard access listed in `?`. Builds with the `app` feature also accept `axiom app`.
- **Plain reports.** The summary board uses Codex luna, falling back to Claude Haiku; select Haiku or turn it off if preferred. Facts come from recorded data. A Haiku narrator writes the final report from the engine digest and core rulings; an optional plain-words translation explains technical text. Usage shows per-model tokens and API-price equivalents, including Codex at the official API rates recorded in this release.
- **Review and fixes.** Review results carry across sibling fixes (`AXIOM_REVIEW_CARRY=0` disables this). Fix chains stop after two rounds; the core can use `orch waive` with a reason or block the wish. Reviewers write their own verdict files with a blocker/major/minor rubric; reports list `needs: smoke/manual` findings.
- **Context and progress.** Dispatchers warn at 80% of the handoff limit and hand off at 150k tokens. Binding rules are restored verbatim after compaction; handoff notes are checked for instructions to hide problems. Rarely used prompt sections load when needed. The no-progress guard stops unchanged continuations instead of re-prompting forever (`AXIOM_IDLE_CONTINUES`, default 3).
- **Self-improvement.** `axiom evolve --dry-run` previews problems in Chronos's own logs for the last seven days. Review it before explicitly running `axiom evolve --repo PATH` against the Chronos source repository. This weekly pass is on demand, not scheduled. The desktop Auto-evolve button asks for confirmation; the CLI start command has no confirmation prompt.
- **Other tools.** `axiom review`, `axiom lint`, `axiom usage`, `axiom wait`, `--advanced-research` and `--resume <id> [text]`. agy (Gemini) can review when Codex cannot, without blocking. Locks, path checks, tree-bound verdicts and child-process limits protect the run.

## Optional and paid

The desktop app, agy, the code graph and the advanced research council are optional. The council is off by default; Fable has a $5 default cap. Summary, narration and optional translation calls also use your model services' quota. Usage dollars are API-price equivalents, not subscription charges.

## Install

Download and extract the archive for your platform. In the extracted folder, run one command:

Windows x64 — `axiom-chronos-2.0.0-windows-x64.zip`:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Linux x64 — `axiom-chronos-2.0.0-linux-x64.tar.gz`:

```sh
sh ./install.sh
```

Windows installs both programs to `%LOCALAPPDATA%\Programs\Axiom Chronos`, adds the user PATH and Start menu shortcut, and upgrades 1.0.0 in place. Close both programs first. Use `-Prefix DIR`, `-NoPath`, `-NoShortcut` or `-NoPlugin` to change those steps. `uninstall.ps1` removes the files, PATH entry and shortcut while keeping `~/.axiom` and the Claude plugin. Linux installs `axiom` to `~/.local/bin`; use `--prefix DIR` or `--no-plugin`, and add the folder to PATH if needed.

Both installers add or refresh the `xinhi6716/axiom-chronos` marketplace and install or update `chronos` when `claude` is available, unless opted out. They print `axiom doctor`; health-check problems do not fail installation. Claude Code and Codex CLI must already be installed and signed in. Bare binaries remain available; `SHA256SUMS` covers every release payload.

Or build it with Rust:

```sh
cargo install --git https://github.com/xinhi6716/axiom-chronos --tag v2.0.0 --locked --bin axiom
cargo install --git https://github.com/xinhi6716/axiom-chronos --tag v2.0.0 --locked --features app --bin chronos
```

The second command is for Windows. Data in `~/.axiom` from 1.0.0 stays readable.

## Known limits

`autoCompactWindow` in the agent definitions has not yet been seen taking effect in a real run. The handoff-note guard has not yet been seen working in a real run either: it is a pattern list and can miss paraphrases. Unit states come from evidence, not notes. The desktop app is Windows only; protocol tests use scripted stand-ins and live-model results vary by project.

## 繁體中文

Axiom Chronos 2.0.0 加入 Windows 桌面應用程式、安裝包，以及減少重讀上下文、擋下更多失敗的引擎修改。完整清單見 [CHANGELOG.md](../../CHANGELOG.md)。

### 重點

- **桌面應用程式。** `chronos` 提供 Run、Wishes、Memory、Usage 與 Settings。Claude 與 Codex 有剩餘額度列，每個額度時窗各有沙漏。另有可保持最上層的迷你視窗、聚焦模式、舒適或緊湊版面、右鍵選單、復原、提示，以及 `?` 列出的鍵盤操作。啟用 `app` feature 的建置也可執行 `axiom app`。
- **白話報告。** 摘要看板用 Codex luna，失敗時改用 Claude Haiku；可指定 Haiku 或關閉。事實取自紀錄。Haiku 敘述員依引擎摘要與核心裁決撰寫最終報告，選用的白話翻譯解釋技術文字。Usage 顯示各模型 token 與 API 定價等值金額，Codex 採本版記錄的官方 API 費率。
- **審查與修補。** 審查結果可沿用到同層修補（`AXIOM_REVIEW_CARRY=0` 可關閉）。修補鏈兩輪後停止，由核心用 `orch waive` 附理由裁決，或將願望列為卡住。審查員依 blocker／major／minor 分級，自行寫入裁決檔；報告列出 `needs: smoke/manual` 發現。
- **上下文與進展。** 調度員達交棒門檻的 80% 時先提醒，150k token 時交棒。壓縮後逐字還原約束規則；交棒備註會檢查是否含有隱瞞問題的指示。少用的提示章節需要時才載入。無進展防護會停止沒有進展的接續，避免無限重複提示（`AXIOM_IDLE_CONTINUES`，預設 3）。
- **自我改進。** `axiom evolve --dry-run` 預覽 Chronos 自己最近七天紀錄中的問題。檢視後，再明確執行 `axiom evolve --repo PATH`，對 Chronos 原始碼儲存庫進行改進。這是手動啟動的每週檢查，不是排程。桌面的自動演進按鈕會詢問確認；CLI 啟動指令沒有確認提示。
- **其他工具。** `axiom review`、`axiom lint`、`axiom usage`、`axiom wait`、`--advanced-research`、`--resume <id> [文字]`。Codex 無法審查時可由 agy（Gemini）接手，且不會卡住流程。鎖、路徑檢查、綁定檔案樹的裁決與子程序限制保護執行過程。

### 選用與費用

桌面應用程式、agy、程式碼圖與進階研究議會都是選用的。議會預設關閉；Fable 預設上限 $5。摘要、敘述與選用的翻譯呼叫也會使用模型服務額度。Usage 的金額是 API 定價等值金額，並非訂閱帳單。

### 安裝

下載對應平台的安裝包並解壓縮，在解壓後的目錄執行一行指令：

Windows x64 — `axiom-chronos-2.0.0-windows-x64.zip`：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Linux x64 — `axiom-chronos-2.0.0-linux-x64.tar.gz`：

```sh
sh ./install.sh
```

Windows 把兩個程式裝到 `%LOCALAPPDATA%\Programs\Axiom Chronos`、加入使用者 PATH 與開始功能表捷徑，可原地升級 1.0.0。升級前請先關閉兩個程式。可用 `-Prefix DIR`、`-NoPath`、`-NoShortcut` 或 `-NoPlugin` 調整。`uninstall.ps1` 移除檔案、PATH 項目與捷徑，保留 `~/.axiom` 與 Claude 插件。Linux 把 `axiom` 裝到 `~/.local/bin`；可用 `--prefix DIR` 或 `--no-plugin`，需要時自行加入 PATH。

### 已知限制

代理定義中的 `autoCompactWindow` 尚未在真實執行中觀察到效果。交棒備註防護也尚未見於真實執行：它使用模式清單，可能漏掉換句話說的指示。單元狀態來自證據，不取決於備註。桌面應用程式僅支援 Windows；協定測試使用腳本替身，真實模型的表現依專案而異。
